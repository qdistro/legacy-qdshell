# Settings → Region/Location

What must be visible when this tab is open:

- Tab header text: "Region" (i18n key `panels.region.title`).
- Subtab bar with at least: "Location", "Date", "Calendar Panel".
- A location input/search control.
- A timezone selector.
- Date/time format settings (24-hour toggle, format dropdowns).
- The standard left-side Settings tab strip is visible.
